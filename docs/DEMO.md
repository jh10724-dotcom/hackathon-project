# Three-minute demo

**0:00–0:25 · The problem**
A broker receives a short email about four new drivers. That email alone does not tell them who starts when, which policy schedule applies, or what still needs verification. Coverage Brain prepares that review across four collaborating agents.

**0:25–1:05 · Watcher and Matcher**
Open the original client message and its later clarification. Select Watcher to show the four hires and distinct start dates. Select Matcher: the issued R2 endorsement replaces R1, already lists two new drivers, and leaves the two future assignments unresolved. Click a citation to show the exact source rather than asking the audience to trust the summary.

**1:05–1:45 · Closer and Scribe**
Select Closer to show two unsent follow-ups: request missing vehicle assignments from the client and applicable issued evidence from the insurer. Select Scribe to show proposed record updates, retained history, and a narrowly scoped learning proposal based on the reviewed correction.

**1:45–2:15 · Broker control**
Explain that approval records a review decision. This version does not send email or apply customer-record changes. Unknowns survive every handoff. A blocked or invalid handoff stops downstream execution.

**2:15–2:45 · What actually runs**
The controller and web application run inside a private Daytona sandbox. Codex makes four distinct model calls, with original evidence and prior packets carried forward. Show the four completed handoffs. A saved run is an actual recorded execution, not a new live run; say which one you are demonstrating.

**2:45–3:00 · Impact and next step**
The intended benefit is less repetitive evidence assembly and fewer missed follow-up questions, while keeping the broker responsible for decisions. Time saved and accuracy improvements are hypotheses to measure with brokers, not established results. Next: evaluate real-document ingestion and connect approved actions to broker systems.

## Before presenting

- Resume the Daytona sandbox and server, then generate a fresh private preview link.
- Open a completed real run; the measured first four-agent run took about 4 minutes 35 seconds, so do not wait for an entire new run in a three-minute pitch.
- Keep the source documents, Closer draft and Scribe proposals ready to show.
- Disclose reuse of the earlier Coverage Brain / AgentForge concept and contract.
- Do not claim live Cognee, email, CRM, insurer or Arize integrations.

## Judging evidence

| Criterion | Demonstrable evidence |
| --- | --- |
| Impact | A specific broker staffing-change review with missing assignments and dated endorsements; impact remains to be measured |
| Technical execution | Four real model invocations, validated handoffs, source citations, persisted review decisions, behavioral and HTTP tests |
| Creativity | Collaboration that distinguishes reported facts, issued evidence, unknowns, and narrowly scoped learning proposals |
| Presentation | One case, one evidence trail, two usable follow-up drafts, and a visible broker decision |
| Sponsor usage | Daytona hosts the actual application and agent runtime, with private previews and reproducible source sync |
