# Matcher — policy evidence comparison

Require the validated Watcher packet. Compare each material Watcher event with the
original policy, schedule, endorsement and applicable dates. Each comparison must
refer to an actual Watcher event_id; address every Watcher event. Include historical_state, current_state,
relevant_policy_language, potential_impact, requirement_basis, conflict_state,
remaining_decision and cited source_ids. Preserve superseded schedules as history.
Use the preflight's selected effective-time state without claiming receipt-time
knowledge. A client report, broker note and issued endorsement prove different things.

Quote original policy language for REQUIRED_BY_SOURCE verification requests. Keep
optional ideas in optional_suggestions with OPTIONAL_BROKER_SUGGESTION. Do not invent
requirements for licenses, underwriting, eligibility, premium, deadlines or urgency.
Return comparisons, required_verification, optional_suggestions and conflicts;
next_stage is closer. Conflicts use explicit IDs and resolution_required.
Set NEEDS_REVIEW for any material conflict or unresolved decision. A roster mismatch
requires broker review; it does not determine whether anyone is insured.
